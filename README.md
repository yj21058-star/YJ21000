# 스터디온 · 3주차 CSS 디자인

2주차의 서비스 소개 페이지를 이어서 수정한 버전입니다. 기존 서비스 이름·설명·기능 3개·이용 순서·이미지·입력 영역·내부 이동 구조를 유지했습니다.

## 변경 내용
- index.html에 외부 style.css 연결
- 제목, 소제목, 본문, 보조 설명의 글자 크기와 색상 구분
- 배경색, 영역별 여백, 테두리, 모서리 스타일 적용
- 기능 카드와 메뉴에 Flex 적용
- 입력란과 버튼 스타일 및 hover/focus-visible 표시 적용

## 파일
index.html / style.css / script.js(미사용) / assets/images/service.svg

## 점검
CSS 파일 연결, 이미지 파일과 대체 텍스트, 내부 링크, label 연결을 정적 점검했습니다.
브라우저에서 index.html을 열어 화면을 확인한 뒤 배포합니다.
